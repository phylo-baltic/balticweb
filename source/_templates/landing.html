baltic

baltic is a Python library for parsing phylogenetic trees. It takes Newick, Nexus, or Nextstrain JSON and allows you to manipulate, explore, and visualize them.

  • Efficient manipulation of phylogenetic trees
  • Advanced analysis for time-scaled phylogenies
  • Flexible visualization tools
  • Integration with Python scientific libraries
  • Support for multiple tree formats

baltic is ideal for:

  • Exploring pathogen evolution
  • Studying speciation and extinction patterns
  • Visualizing evolutionary relationships
  • Integrating phylogenetic + metadata
